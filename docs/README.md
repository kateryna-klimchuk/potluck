# Docs

- `prd/` — Product Requirement Documents. One per feature/initiative. Numbered `NNNN-slug.md`.
- `adr/` — Architecture Decision Records. Immutable once accepted; supersede instead of editing. Numbered `NNNN-slug.md`.

Templates: `prd/0000-template.md`, `adr/0000-template.md`.
Use the `/write-prd` and `/write-adr` Claude skills to create new ones.
